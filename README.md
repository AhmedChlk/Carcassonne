# Carcassonne - Projet de fin de semestre L2 Informatique

## Description 
Implémentation du jeu de société Carcassonne en tant que projet de fin de semestre pour la L2 informatique.
Ce projet consiste à développer une version numérique du célèbre jeu de placement de tuiles avec interface console.

## Fonctionnalités implémentées
- ✅ Placement de tuiles selon les règles
- ✅ Système de score
- ✅ Interface console intuitive
- ✅ Gestion des meeples
- ✅ Détection de fin de partie
- ✅ Mode multijoueur local

## Technologies utilisées
- Langage : C
- Gestion de projet : Git

## Compilation et exécution
```bash
make run
```
